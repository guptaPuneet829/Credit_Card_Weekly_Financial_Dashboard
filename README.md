💳 Credit_Card_Weekly_Financial_Dashboard

*To create a weekly dashboard for credit cards that is exhaustive and offers real-time insights into key performance metrics and trends, thereby allowing stakeholders to monitor and analyze credit card operations effectively.*

# 📌 Project Overview

The **Credit Card Financial Dashboard** is an interactive Business Intelligence solution developed using **Microsoft Excel** and **Power BI** to analyze customer transactions and financial performance throughout **2023**.

The dashboard transforms raw financial data into meaningful business insights, enabling stakeholders to monitor revenue, customer demographics, spending behavior, transaction trends, and credit card performance through interactive visualizations.

# 🎯 Business Objective

The objective of this project is to help financial institutions answer key business questions, such as:

- What is the overall revenue generated?
- Which customer segments contribute the highest revenue?
- Which credit card categories perform the best?
- How do customer income, education, and occupation influence revenue?
- Which expenditure categories generate maximum revenue?
- How do revenue and transactions change throughout the year?

### 2️⃣ Data Modeling

- Created relationships between tables
- Developed DAX measures for KPI calculations

### 3️⃣ Dashboard Development

Designed an interactive two-page dashboard with dynamic filters, KPI cards, charts, and business insights.
